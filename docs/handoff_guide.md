# 手改操作指引（零預算路線核心）

對象：`corpus/ai/round4_13_urbanisation_v095.txt`（v0.95，預期 AI 率 15-20% 區間）
你的 A+ 錨點實測 0%——你的手就是 0% 發生器。這份指引把 26%→個位數的最後一程交給你的手。

## 為什麼有效（校準階梯背書）

| 版本 | AI 率 |
|---|---|
| 你的 A+ 真人文 | 0% |
| v0.9（+8 語法滑落） | 26% |
| v0.8 | 37% |
| R4.9 原版 | 41% |

真人手改會同時注入兩種儀器看不見的東西：(1) 你本人的錯誤分佈（和錨點同源）；(2) 語義層的個人漂移（循環重述、用詞偏好）。兩者正是我們離線儀器全部失明的維度。

## 操作流程（每段 5-8 分鐘）

1. **逐段讀** v0.95，理解論點和引用（引用和數據原樣保留，不要動）。
2. **不看原文，用自己的話重敲該段**（可以偷看論點順序和數據，但句子要從你手裡出）。允許：
   - 你自然會犯的錯（就是錨點裡那些類型——主謂、冠詞、介詞，不用刻意修）
   - 同一個意思換你的說法（「大規模」你常說 which shows / proving 這種，跟著你的直覺）
   - 句子長短跟你的感覺走（錨點的長短方差大）
3. 敲完對照原文檢查：論點沒漏、數據沒錯、引用格式完整。
4. 下一段。

## 三條紅線

- **引用句不要手滑**：作者名、年份、括號格式原樣（你 A+ 文裡引用句反而是乾淨的）。
- **不要用任何工具「順一遍」**：Grammarly / 翻譯來回 / humanizer 一律禁止——每次工具加工都會重新注入 AI 指紋（拋光定律，實測 +10~15%）。
- **改完不要再貼給 AI 讓它「看看」**——包括我。過了零接觸線就只有你的手。

## 完成後
