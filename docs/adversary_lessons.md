# 對手流水線教訓錄 — vvvjb18-lab/naturalizer-workflow (v7.5) 分析

> 來源：https://github.com/vvvjb18-lab/naturalizer-workflow
> 性質：反面教材（架構）＋ 參考數據（~20 次真實 Turnitin 校準點）
> 本檔只吸收方法論與數據教訓，不使用其委託交付證據。

## 一、他們的架構（已被證明是死路）

generate（本地模型）→ humanizer-12b 改寫 → 段落 crossover 重組 → grind 磨段落（3-5 輪 × 每輪最差 3 段）→ NLI 閘門 → LanguageTool 修語法 → surgery 補刀。七層後處理，每層在修上一層造成的損傷。

**核心數據（calibration.json）：**
- 「拋光定律」：每次 API 潤飾，Turnitin 分數 +10~15%/級。過 <20% 的文本全部是**零或極輕潤飾**、且殘留語法損傷 0.02–0.06 的——即：**只能靠保留爛英文過檢**。品質天花板無解。
- grind 統計：7 段成功 / 9 段無改善 / 4 段被驗證拒絕——邊際收益極差。
- final6.0：離線分 0.058（很低）→ 真實 Turnitin **56%**。離線 gen 分數與 Turnitin **非單調**：A1 V2 離線 0.959 → Turnitin 0%；V7 離線 0.980 → 31%。README 宣稱的「≤0.05 → <20%」被自家數據反例推翻。
- 他們自己的結論（Lesson 24）：單一特徵映射失敗，雙特徵規則勉強 9/9——**句長方差（CV/burstiness）是最強預測子**，通過帶 0.45–0.65；CV≤0.28 必掛；比原文更平滑的文本高風險（0.390 → 56%）。
- 注意：他們的 CV 公式未公開，數值不能直接與我們的 burstiness_cv 對齊（他們通過文本 0.5–0.65，疑似超過自然人類區間=人為變形節奏）。**只取方向性結論，不進口閾值。**

## 二、吸收進本項目的經驗

1. **「過閘後零接觸」規則**（源於拋光定律）：文章通過雙閘門後，禁止任何工具再碰——不 humanizer、不 LanguageTool、不 Grammarly、不 API「最終檢查」。任何一次 LLM 加工都會重新注入指紋（他們實測 +10~15%/級）。
2. **迭代=整篇重寫，絕不局部修補**：他們的 EditLens 顯示 Turnitin 會抓「AI 修訂 delta」（final5.1 edit 0.24 → 25%）——被 AI 改過的文本本身就有指紋。我們的迭代循環必須是「更新契約→全新生成」，不是「哪句違規改哪句」。
3. **節奏（burstiness）是 Turnitin 的頭號特徵**：我們的契約已定 0.30–0.46（真人區間）；據其數據把下限提高到 0.32，目標帶 0.33–0.46，遠離平滑區。
4. **文體分區確認**：第一人稱敘事=綠區（天生好過）；正式第三人稱議論=紅區（最難）。我們的目標文體（EAP discursive）正是紅區——預期需要多輪迭代，且證明他們的 grind 也沒在紅區做到「過檢+保品質」，只能二選一。我們的生成端模仿路線是未經他們驗證的第三條路。
5. **逐句 perplexity 作為診斷定位器**（他們 Lesson 19，單調有效）：檢測器集成要支持句子級輸出，模仿 Turnitin 報告的句子高亮，用於反向定位問題句。GPT-2 perplexity 單獨做分類很弱，但做「找出我最低困惑度的句子」的定位器有用。
6. **提交紀律參考**：他們的接受帶 <30% 可接受 / <20% 理想；離線分 0.24+ 永不提交。我們的紀律更嚴：連續 5 篇雙閘門全過才動用真實名額；真實檢測 ≥20% → 凍結名額、全量複檢校準、修訂契約後才恢復。
7. **高溫採樣經驗**：他們的 candidate 採樣 temp 0.9–1.1 提升節奏方差。僅對 Phase 3（本地 LoRA 推理）有用，記錄備用。

## 三、明確拒絕的部分

- 後處理七層架構（品質死路，用戶已親身驗證）
- 以 humanizer-12b 為核心（口語跨文體改寫器，非學術模型）
- LanguageTool 修復層（在修 humanizer 造成的傷，治標製造新標）
- 數字斗篷 ZXQ 佔位符替換（只在「後處理改寫」架構下需要；我們一次成型，無此需求）
- 他們的離線 gen 分數目標（被他們自己的數據證偽）
- 把 CV 推到 0.5–0.65 的「變形節奏」（超出人類自然區間，本身是指紋，且伴隨語法損傷）
- 他們的校準數據衛生（自認校準檔損壞、pre-8.9 標籤低估需重測）——所有數字當量級參考，不當精確依據

## 四、對我們路線的含義

他們用 20 次真實檢測證明了兩件事：(1) 後處理路線的「過檢」與「品質」不可兼得；(2) Turnitin 的核心權重在句法節奏層。我們的生成端模仿（在真人統計分佈內寫作）恰好同時回應這兩點：品質由契約的學術公式保證，節奏由真人區間校準保證。若我們多輪後仍過不了，正確的後備是**更多真人語料收緊區間 + 收緊契約 + LoRA**，而不是回頭走 grind。
